# Pet Shop Database — Study Guide

This guide explains how to install MySQL, create and populate the Pet Shop database, and run the practice exercises. Each file name is shown next to its direct GitHub link.

## 1. Prerequisites: Install MySQL

Choose the installation guide for your operating system:

| Operating system | File | Direct link |
|---|---|---|
| macOS | `Tutorial_mysql-macos_Install.md` | [Open file on GitHub](https://github.com/profclovesrocha/database/blob/main/slides/Live%20-%20Projeto%20Cyber%20Database%202026/Tutorial_mysql-macos_Install.md) |
| Windows | `Tutorial_mysql-windows_Install.md` | [Open file on GitHub](https://github.com/profclovesrocha/database/blob/main/slides/Live%20-%20Projeto%20Cyber%20Database%202026/Tutorial_mysql-windows_Install.md) |

Complete the installation and make sure the MySQL server is running before continuing.

## 2. Create and Populate the Database

After MySQL is installed and running, execute the following SQL scripts **in this exact order**.

| Step | Purpose | SQL file | Direct link |
|---|---|---|---|
| 1 | Generate the database | `03-Create_DB_PetShop.sql` | [Open SQL script](https://github.com/profclovesrocha/database/blob/main/slides/Live%20-%20Projeto%20Cyber%20Database%202026/03-Create_DB_PetShop.sql) |
| 2 | Load the data | `04-Load_Data_PetShop.sql` | [Open SQL script](https://github.com/profclovesrocha/database/blob/main/slides/Live%20-%20Projeto%20Cyber%20Database%202026/04-Load_Data_PetShop.sql) |

Run Step 2 only after the database has been created successfully.

## 3. Run the Exercises

Once the database has been created and populated, run the following scripts.

| Step | Purpose | SQL file | Direct link |
|---|---|---|---|
| 3 | Create users and roles | `05-Create_Users_Roles.sql` | [Open SQL script](https://github.com/profclovesrocha/database/blob/main/slides/Live%20-%20Projeto%20Cyber%20Database%202026/05-Create_Users_Roles.sql) |
| 4 | Test queries and reports | `06-Report_Queries.sql` | [Open SQL script](https://github.com/profclovesrocha/database/blob/main/slides/Live%20-%20Projeto%20Cyber%20Database%202026/06-Report_Queries.sql) |

## 4. Execution Order — Quick Reference

1. `03-Create_DB_PetShop.sql` — create the database.
2. `04-Load_Data_PetShop.sql` — load the data.
3. `05-Create_Users_Roles.sql` — create users and roles.
4. `06-Report_Queries.sql` — test queries and reports.

> **Important:** Do not run the data-loading script before creating the database. Run the user/role and query/report exercises only after the database has been created and populated.
